# 🧮 Simulador de IRPF 2025

> Calculadora interativa do Imposto de Renda da Pessoa Física com tabela progressiva vigente em Janeiro/2025.

🔗 **[Acesse o projeto ao vivo](https://vanessenceweb.github.io/simulador-irpf/)**

---

## 📋 Sobre o Projeto

Projeto prático desenvolvido para a disciplina de **Programação para Web** no curso de **Sistemas para Internet** da **UNICAP — Universidade Católica de Pernambuco**.

O simulador permite calcular o IRPF mensal com base no salário bruto informado, exibindo:

- 💰 Valor do imposto a recolher
- 📊 Alíquota efetiva sobre o rendimento
- 🧾 Detalhamento do imposto por faixa de renda
- 📄 Exportação do resultado em PDF

---

## ✨ Funcionalidades

- [x] Cálculo automático do IRPF com a tabela de Janeiro/2025
- [x] Exibição da alíquota efetiva
- [x] Breakdown do imposto por faixa progressiva
- [x] Visualização gráfica (barra de alíquota efetiva)
- [x] Download/impressão do resultado em PDF
- [x] Seção educativa: o que é IRPF, como funciona o cálculo progressivo e glossário
- [x] Layout responsivo
- [x] Design limpo e acessível

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/vanessenceweb/simulador-irpf.git

# Entre na pasta do projeto
cd simulador-irpf

# Abra o arquivo index.html no seu navegador
# (não requer servidor — é puro HTML/CSS/JS)
```

Ou simplesmente abra o `index.html` diretamente no navegador. ✅
